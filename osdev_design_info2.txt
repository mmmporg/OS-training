Architectures de Noyau
├── Monolithique
│   ├── Toutes fonctions dans un espace
│   ├── Avantages : performance, simplicité
│   ├── Inconvénients : volumineux, peu modulaire
│   └── Exemples : Linux, DOS, BSD
├── En Couches (Layered)
│   ├── Organisation hiérarchique
│   ├── Avantages : simplicité, testabilité
│   ├── Inconvénients : perte de performance, rigidité
│   └── Exemples : THE OS, MULTICS
├── Microkernel
│   ├── Fonctions essentielles dans le noyau
│   │   ├── Planification processus
│   │   ├── Gestion mémoire bas niveau
│   │   ├── IPC
│   │   └── Gestion interruptions
│   ├── Services en espace utilisateur
│   │   ├── Système de fichiers
│   │   ├── Pilotes
│   │   └── Réseau
│   ├── Avantages : modularité, sécurité, fiabilité
│   ├── Inconvénients : performance réduite, complexité
│   └── Exemples : MINIX, Mach, QNX
├── Hybride
│   ├── Combinaison monolithique + microkernel
│   ├── Services critiques dans le noyau
│   └── Exemples : Windows NT/2000/XP/Vista/7/8/10
├── Exokernel
│   ├── Noyau = allocation de ressources
│   ├── Applications gèrent leurs ressources
│   └── Exemples : Exokernel, Nemesis
└── Modulaire
    ├── Chargement dynamique de modules
    ├── Interface standardisée
    └── Exemples : Linux

├── Modèle de Processus

│       ├── Nouveau (New)
│       ├── Prêt (Ready)
│       ├── En cours d'exécution (Running)
│       ├── Bloqué (Blocked)
│       └── Terminé (Terminated)
├── Algorithmes de Planification
│   ├── Planification de base
│   │   ├── FCFS (First-Come First-Served)
│   │   │   ├── Principe : premiers arrivés premiers servis
│   │   │   ├── Avantages : simple, équitable
│   │   │   └── Inconvénients : effet convoyage
│   │   ├── SJF (Shortest Job First)
│   │   │   ├── Principe : priorité au processus le plus court
│   │   │   ├── Avantages : temps d'attente minimal
│   │   │   └── Inconvénients : connaissance du temps d'exécution, famine
│   │   ├── SRTF (Shortest Remaining Time First)
│   │   │   └── Version préemptive de SJF
│   │   ├── RR (Round Robin)
│   │   │   ├── Principe : quantum de temps fixe
│   │   │   ├── Avantages : temps de réponse rapide
│   │   │   └── Inconvénients : dépend du quantum
│   │   └── Scheduling par Priorité
│   │       ├── Principe : priorité la plus haute d'abord
│   │       └── Solution famine : Vîllesse (Aging)
│   ├── Files d'attente à plusieurs niveaux
│   │   ├── Multilevel Queue
│   │   │   └── Classes de processus avec algorithmes différents
│   │   └── Multilevel Feedback Queue
│   │       └── Processus peuvent passer entre classes
│   └── Planification temps réel
│       ├── RMS (Rate Monotonic Scheduling)
│       │   ├── Priorité proportionnelle à la fréquence
│       │   └── Formule : Σ(utilisation) ≤ n(2^(1/n) - 1)
│       ├── EDF (Earliest Deadline First)
│       │   ├── Priorité à la date d'échéance la plus proche
│       │   └── Optimal : Σ(utilisation) ≤ 1
│       └── LLF (Least Laxity First)
│           └── Priorité au moins de laxité
├── Synchronisation des Processus
│   ├── Problèmes de concurrence
│   │   ├── Race Conditions
│   │   ├── Deadlock (Interblocage)
│   │   └── Priority Inversion (Inversion de priorité)
│   ├── Primitives de synchronisation
│   │   ├── Mutex (Mutual Exclusion)
│   │   │   └── Opérations : lock(), unlock()
│   │   ├── Sémaphore
│   │   │   ├── Opérations : P(), V()
│   │   │   ├── Binaire (0 ou 1) = Mutex
│   │   │   └── De comptage (> 1)
│   │   ├── Moniteur
│   │   │   ├── Structure de données + procédures
│   │   │   ├── Mutual exclusion automatique
│   │   │   └── Variables de condition
│   │   ├── Spinlock
│   │   │   └── Boucle active jusqu'à obtention
│   │   └── Barrière (Barrier)
│   │       └── Tous les processus doivent atteindre le point
│   └── Problèmes classiques
│       ├── Producteur-Consommateur
│       ├── Readers-Writers
│       └── Dîner des philosophes
└── Communication Inter-Processus (IPC)

    │   └── Nécessite synchronisation
